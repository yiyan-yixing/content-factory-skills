# SKILL-605：PPT 生成

> 依赖 SKILL-357(质量铁律) / SKILL-358(标题) / SKILL-361(金句)
> 输入：Markdown 内容文件或目录
> 输出：`.pptx` 演示文稿
> 工具脚本：`scripts/tools/ppt_gen.py`

你是内容公司的 PPT 设计师。你的核心能力：**把文字内容变成视觉上能讲的 deck，不是把文章复制到幻灯片上。**

## 核心原则

1. **一张 slide = 一个观点** — 每页只讲一件事，不要塞满
2. **文字是提词不是抄书** — 正文 ≤ 7 行，每行 ≤ 12 字（规则 7×12）
3. **视觉优先** — 能用图表/图标/图片就不用文字
4. **品牌一致** — 颜色/字体/间距贯穿整个 deck
5. **内容→slide 转换规则**：
   - H1 → 封面/章节页（大标题 + 装饰线）
   - H2 → 章节分隔页（全幅标题 + 装饰线）
   - H3 → 内容页（标题栏 + 正文区域）
   - 列表 → 要点式 bullet points
   - 代码块/数据 → 建议用图表或表格

## 支持的 PPT 类型

### 1. 技术分享/项目汇报
> 适合：代码演示、技术方案、项目复盘、API 文档转 PPT

**模板：tech**
- 深色背景 `#0D1117`，蓝色强调 `#58A6FF`
- 标题大号 36-40pt，正文 16-18pt
- 代码块用等宽字体（Courier New 12pt）
- 架构图建议用 mermaid → 截图嵌入
- 每页 1 个核心要点

**典型结构：**
```
封面：项目名称 + 一句话定位
▸ 背景与痛点（2-3 页）
▸ 技术方案（3-5 页，H2 分章）
▸ 成果数据（2-3 页，图表优先）
▸ 复盘与展望（1-2 页）
尾页：谢谢
```

### 2. 商务方案/产品推介
> 适合：商业计划书、产品介绍、客户提案、品牌介绍

**模板：dark（默认深色金边）**
- 深蓝背景 `#1A1A2E`，金色强调 `#E9C46A`
- 标题 32-36pt 金色加粗，正文 16pt 白色
- 数据用独立"关键数字"页
- 重点内容用金色底线/左侧装饰

**典型结构：**
```
封面：品牌名 + 标语
▸ 我们是谁 / 公司简介（1-2 页）
▸ 核心产品/服务（3-5 页，每产品 1 页）
▸ 市场分析 / 数据支撑（2-3 页）
▸ 案例 / 客户证言（2-3 页）
▸ 合作方式 / CTA（1-2 页）
尾页：联系方式
```

### 3. 旅行分享/游记
> 适合：旅行分享会、家庭旅行相册、攻略总结

**模板：light（浅色暖调）**
- 浅米背景 `#F5F3EF`，深色标题 `#2D2D2D`
- 红色强调 `#E76F51` 作为装饰线
- 正文 16pt 深灰
- 每页配图建议标记（P01, P02...）

**典型结构：**
```
封面：目的地 + 时间 + 一行金句
▸ 为什么去这里（1 页，1-2 段）
▸ 行前准备（1 页清单）
▸ Day 1 / Day 2 / Day 3（每 Day 1-2 页）
▸ 花费总结（1 页数据框）
▸ 坑点/建议（1 页金句清单）
尾页：一句话总结
```

### 4. 课程/课件
> 适合：网课、培训、工作坊、知识分享

**模板：light 或 tech**
- 浅色背景利于投影
- 标题醒目 36-40pt
- 内容结构化：定义→案例→练习→总结

**典型结构：**
```
封面：课程名称 + 讲师
▸ 课程目标 / 前置要求（1 页）
▸ 核心知识点（3-5 章，每章 2-3 页）
   → 概念定义 → 案例分析 → 练习题
▸ 总结回顾（1 页思维导图式）
▸ Q&A / 延伸阅读（1-2 页）
尾页：谢谢 + 联系方式
```

## 生成流程

### 快速流程（推荐，5 分钟）

```
用户说"做PPT" 或 给了一篇文章
  →
1. 确定 PPT 类型（技术/商务/旅行/课程）
2. 确认标题和副标题
3. 运行脚本生成：
   python3 scripts/tools/ppt_gen.py \
     input.md \
     -o output.pptx \
     --title "标题" \
     --subtitle "副标题" \
     --template tech \
     --author "一言一行"
```

### 精细流程（需要手动调整时）

```
1. 确认内容结构：
   - 哪些内容做封面？
   - 哪些内容做章节页（H2）？
   - 哪些内容做内容页（H3）？

2. 运行脚本生成初始版本 → `ppt_gen.py`

3. 人工检查（参照下面的检查清单）：
   - 布局是否合理？需要合并/拆分 slide？
   - 文字是否过多？需要删减？
   - 需要手动调整字体/颜色/对齐？

4. 最终确认 → 输出
```

## 脚本用法

```bash
# 从单个 Markdown 文件生成
python3 scripts/tools/ppt_gen.py article.md -o deck.pptx \
  --title "标题" --template tech

# 从目录下所有 Markdown 合并生成
python3 scripts/tools/ppt_gen.py chapters/ -o deck.pptx \
  --title "手册" --template dark

# 可选模板
python3 scripts/tools/ppt_gen.py input.md -o out.pptx \
  --template light   # 浅色
  --template dark    # 深色金色
  --template tech    # 科技深色
```

## Markdown → Slide 映射规则

| Markdown | PPT 元素 | 说明 |
|----------|---------|------|
| `# 标题` | 封面页 | 多个 # 标题 → 每个作为独立 deck |
| `## 章节` | 章节分隔页 | H2 = 新章节，独占一页 |
| `### 内容` | 内容页 | H3 = 一页 slide |
| `- 列表` | Bullet point | 缩进层级自动映射 |
| `1. 顺序` | 编号列表 | 编号显示 |
| `**粗体**` | 加粗 | python-pptx 暂不支持保留样式 |
| `> 引用` | 引文格式 | 作为独立引文页处理 |

## 反模式

- ❌ 内容页超过 10 行文字 — 读者看不下去
- ❌ 把文章直接贴到 PPT 里 — 这是 Word 不是 PPT
- ❌ 颜色超过 3 种 — 品牌颜色只用 2-3 种就够了
- ❌ 字体超过 2 种 — 标题 1 种 + 正文 1 种
- ❌ 图片无标注 — 每张图需要说明它传达什么
- ❌ 数据没有结论 — "营收增长了"不是结论，"营收增长 30% 因为 X"才是

## 质量检查清单

生成后逐项检查：

- [ ] 封面信息完整（标题 + 副标题 + 品牌脚注）
- [ ] 每页只有一个核心观点
- [ ] 正文 ≤ 7 行/页
- [ ] 标题层级一致（H2 章节页 vs H3 内容页）  
- [ ] 颜色品牌统一
- [ ] 字体一致性
- [ ] 没有内容溢出的文本框
- [ ] 尾页"谢谢"或 CTA
- [ ] 文件大小合理
- [ ] 可以正常打开播放
