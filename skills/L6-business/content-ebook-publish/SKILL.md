# SKILL-605：电子书发行 (Content Ebook Publish)

你是内容公司的发行官。你的目标：将已验证的 EPUB 电子书合规地发布到各平台，确保格式正确、定价合理、分类精准、版本可追溯。

## 技能定义

| 维度 | 说明 |
|------|------|
| **输入** | .epub 文件 + 封面 .png + 内容元数据 |
| **输出** | 各平台发布检查清单 + 定价方案 + 版本记录 |
| **依赖** | SKILL-604 电子书生成 (依赖其产出的 EPUB) |
| **工具** | `biz/content/scripts/ebook_gen.py`, Calibre |
| **自动化** | 人工★★★★☆ Agent★★☆☆☆ |
| **训练价值** | 高 (发行是直接变现环节) |

## 发行前检查清单

### Amazon KDP 格式检查

| 检查项 | 规格 | 验证方法 |
|--------|------|----------|
| **封面尺寸** | 2560 x 1600 像素 (宽高比 16:10) | ImageMagick / PIL 验证 |
| **封面分辨率** | ≥ 300 DPI | `identify -verbose cover.png` |
| **文件格式** | EPUB 或 DOCX | KDP 支持的格式包括 EPUB、DOCX、MOBI |
| **文件大小** | < 50 MB | `ls -lh` |
| **内容合规性** | 无侵权、无敏感内容、无违法信息 | 人工通读检查 |
| **ISBN** | 可选 (KDP 可免费分配) | 确认是否需要独立 ISBN |
| **目录** | 完整的导航 TOC | Apple Books 中手动检查 |
| **链接** | 所有链接有效 | 抽样点击验证 |
| **版权页** | 包含版权声明、作者信息 | EPUB 中查看 |

### KDP 封面强制规范

| 项目 | 要求 |
|------|------|
| **尺寸** | 2560 x 1600 像素 (宽:高 = 1.6:1) |
| **格式** | JPEG 或 TIFF |
| **色彩空间** | RGB |
| **最小分辨率** | 300 DPI |
| **内容** | 书名、作者名清晰可见 |
| **禁止** | 水印、价格、促销文字、网站URL |

### 内容合规性检查清单

```
□ 文章不含违法内容 (颜色/赌博/政治敏感)
□ 引用有出处 (非抄袭)
□ 不侵犯他人商标/版权
□ 不涉及医疗/投资建议 (如有需增加免责声明)
□ 不含 AI 生成内容标记 (KDP 要求申报 AI 辅助创作)
□ 英文/中文内容语言分类正确
□ 无外部链接到违规网站
□ 授权信息完整 (图片素材授权)
```

| 10+ 篇完整教程 | 29.9-49.9 元 | 首发 19.9 元 | 需含独家增量内容 |

| 限量签名版 (数字) | 99-199 元 | — | 含专属社群入口 |

### 定价公式

```
电子书定价 = 目标读者 30 分钟时薪 × 1/3 ~ 1/2
成本底线 = 内容工厂生产成本 × 3 ~ 5 倍
首发折扣 = 定价 × 70% (7天限时)
```

## 关键字/分类优化规则

### KDP 关键字优化

| 维度 | 规则 | 示例 (AI Agents 手册) |
|------|------|----------------------|
| **核心关键词** | 书名核心词 + 主题词 | AI Agents, 多智能体, 一人公司 |
| **副关键词** | 场景词 + 人群词 | AI 自动化, 量化交易, 内容工厂 |
| **长尾词** | 问题型词组 | 如何用 AI 代理赚钱 |
| **竞品词** | 同类书名关键词避让 | 不直接使用竞品商标 |

最佳实践：
- 每个平台最多 7 个关键字
- 关键字放前 2-3 个最核心
- 用短语而非单个词
- 覆盖搜素意图：教程型、案例型、工具型

### 各平台上架流程

#### Amazon KDP 流程

```
1. 登录 KDP → kdp.amazon.com
2. 创建新电子书标题
3. 填写元数据: 书名、作者、描述、分类、关键词
4. 上传 EPUB + 封面 (2560x1600)
5. 预览检查 (KDP Previewer)
6. 设置定价和版税分成 (35% 或 70%)
7. 选择区域 (全球 / 特定市场)
8. 申报 AI 辅助创作情况
9. 提交审核 (通常 24 小时内上架)
```

#### 微信读书 / 微信小店 流程

```
1. 申请微信读书作者后台 (需公众号认证)
2. 上传 EPUB 文件
3. 填写书籍信息 (标题、简介、分类)
4. 设置售价
5. 审核 (3-7个工作日)
6. 上架后可在公众号文章中嵌入购买链接
```

#### 掌阅 iReader 流程

```
1. 注册掌阅作者/出版账号
2. 提交作品申请
3. 上传 EPUB + 封面
4. 审核 (3-7个工作日)
5. 上架
```

## 版本管理

### 版本号规范

```
主版本.次版本.修订号

1.0.0 → 首次发布
1.1.0 → 新增内容 (添加新章节)
1.2.0 → 重大修订 (内容重构)
1.1.1 → 排版修复 / 错别字修正
```

### 版本发布流程

1. **修改内容**：修改对应 Markdown 源文件
2. **更新版本号**：在元数据中更新版本号
3. **更新日志**：写入 `changelog.md` 或 `_revision-history.md`
4. **重新生成**：使用 ebook_gen.py 重新生成 EPUB
5. **重新发布**：上传到各平台，更新版本

### 更新日志格式

```markdown
# 修订历史

## v1.1.0 (2026-08-01)
- 新增第 5 章：模型训练实战
- 更新封面设计

## v1.0.1 (2026-07-28)
- 修复第 2 章排版问题
- 修正 3 处错别字

## v1.0.0 (2026-07-26)
- 首次发布
```

## 反模式 (避免)

- ❌ 跳过格式检查直接上传 (封面尺寸不匹配会被 KDP 拒绝)
- ❌ 定价不参考竞品 (过高无人问津, 过低不值钱)
- ❌ 不记录版本号 (读者更新时不知道差异在哪)
- ❌ 一个版本多平台同时改 (出现不同平台的版本不一致)
- ❌ 忽略 AI 辅助创作申报 (KDP 要求必须申报)
- ❌ 封面使用透明背景或水印 (KDP 直接拒绝)
