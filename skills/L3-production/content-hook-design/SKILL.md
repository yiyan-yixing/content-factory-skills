# SKILL-360: 开头钩子设计

> 从阿里云27篇+爆款公众号+小红书数据提炼
> 核心判断：开头决定读者是否继续——3秒定生死

## 3种开头公式

### 1. 痛点连击型（最强——阿里云27篇中18篇用此法）

**公式：** 痛点2-5连击 + 判断句（"不是A而是B"）

**结构：**
```
[痛点1场景] + [痛点2场景] + [痛点3场景]……
[判断句：不是X，而是Y]
```

**示例（阿里云）：**
> 你是不是也经历过这些瞬间？
> 凌晨两点，Agent又"自信地"宣布任务完成——测试全绿、CI全过。你点开diff，发现它删了三个兼容分支。
> 一个会话里它像高级架构师，下一个会话像刚入职的实习生。
> 你写了一份800行的AGENTS.md，它读完前200行就开始幻觉。
> 瓶颈不在模型够不够聪明，而在我们有没有把它"装"好。

**示例（我们的XHS）：**
> 17个候选Alpha跑完回测，0个通过——不是运气差，是A股的alpha薄得像纸。

**规则：**
- 痛点必须是读者能"点头"的（"你是不是也..."）
- 每个痛点1-2句话，不能展开（展开在正文）
- 最后一句必须是判断句，点明本质
- 判断句用"不是A而是B"格式

### 2. 反直觉断言型（适合技术观点文）

**公式：** 反常识结论 + 1-2句数据支撑 + "为什么"

**结构：**
```
[反常识陈述]
[1-2句真实数据/经历]
[为什么？]
```

**示例（阿里云）：**
> 我曾经用一个不断膨胀的CLAUDE.md解决AI"不守纪律"的问题——它确实管用了三天。
> 然后问题以更严重的形式回来了。
> 对付AI的不确定性，堆prompt是负债，做框架才是资产。

**示例（我们的T1-001）：**
> Sharpe=1.03看起来过了线，但我亲手把它毙了——不是不想要，是不敢要。

**规则：**
- 第一句必须让读者"咦？"（意外感）
- 数据/经历必须真实且具体
- "为什么"制造悬念，驱动继续阅读

### 3. 场景代入型（适合实操/故事类）

**公式：** 具体时间+具体场景+具体动作/结果

**结构：**
```
[时间] + [地点/场景]
[具体发生了什么]
[关键发现/转折]
```

**示例（我们的T1-003）：**
> 凌晨2:17收到邮件：@quant-backtest完成了H009a的OOS回测，Sharpe=1.12。同时5个AI在夜间值班。但它们一分钱也不能花、一行代码也不能上线。

**示例（阿里云）：**
> 早上7:30，我打开晨报：3个回测结果，2篇内容草稿，1个市场异动标记，零未授权操作。

**规则：**
- 时间必须具体（不说"有一天"，说"凌晨2:17"）
- 场景必须有感官细节（邮件、屏幕、数字）
- 结果必须有张力（Go了但不能上线 / 全通过了但结果是0）

## 平台适配

| 平台 | 推荐开头型 | 长度 | 关键 |
|------|-----------|------|------|
| 小红书 | 痛点连击/反直觉 | 2-3行（≤60字） | 第一行必须出数字或反常识 |
| 公众号 | 痛点连击 | 3-5行（≤150字） | 判断句收束 |
| X Thread | 反直觉/场景 | 1条tweet（≤280字符） | 首条=整条Thread的生死线 |
| 知乎 | 痛点连击+学术 | 5-8行 | 可以比公众号更长，但必须有趣 |

## 禁忌开头

❌ **信息陈述型** — "今天给大家分享XX" / "本文将介绍XX"
❌ **背景铺垫型** — "随着AI的发展..." / "近年来..."
❌ **自谦型** — "我不太懂XX，但是..." / "分享一下我的浅见"
❌ **问题型（无冲击力）** — "你知道XX吗？" / "什么是XX？"

## 自检清单

- [ ] 前3行是否能让读者"必须继续读"？
- [ ] 是否包含数字/具体场景/反常识？
- [ ] 是否有判断句点明本质？
- [ ] 换成信息陈述写法是否更弱？（如果是，说明改对了）
