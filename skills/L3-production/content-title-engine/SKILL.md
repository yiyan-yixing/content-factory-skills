# SKILL-358: 标题工程

> 从阿里云27篇+52个小红书对标账号+爆款案例提炼
> 优先级: P0 — 标题决定80%点击率

## 标题公式（7类，按效力排序）

### Tier 1: 必用（均分≥4.5）

**1. 数字冲击型（均分4.67）**
公式：`[大数字] + [负面结果/零结果]` 或 `[数字] + [反常识结论]`
- 17个策略0个Go：我的AI团队交了一份零分答卷
- 5人7天干完20人数周的活
- Sharpe=1.03的策略，我否了
- 规则：数字必须具体（不说"很多"，说"17个"）；结果必须意外

**2. 反直觉型（均分4.50）**
公式：`[常识] + 但/却 + [反常识结果]` 或 `[看似好的东西] + [否定]`
- AI不缺智商缺纪律
- 最好的策略最危险
- 代码越写越少，产出越来越多
- 规则：反直觉不能硬造，必须有真实数据/经历支撑

**3. 类比型（均分4.50）**
公式：`[专业概念]：像[日常类比]一样[动词]` 或 `[专业概念]的[日常类比]`
- 给野马套上缰绳：Agent Harness工程实践
- Mac本地AI：像开手动挡一样累但每个挡位都清楚
- 量化选股像民意调查——样本不够结论不可信
- 规则：类比必须是读者能在0.3秒内脑补出画面的日常场景

### Tier 2: 常用（均分4.0）

**4. 演进型（均分4.00）**
公式：`从[A]到[B]：[递进结论]` 或 `[A]→[B]：[关键转折]`
- 从17个全失败到找到1个真信号
- 从"对马喊话"到"给马造高速公路"
- 规则：A和B必须有明确的递进关系，不能并列

**5. 恐惧清单型（均分4.00）**
公式：`做[X]最容易[Y]的N种方式` 或 `N个坑/陷阱/雷`
- 一个人做量化最容易亏的3种方式
- Mac本地跑AI的4个大坑
- 规则：N≤5；每个坑必须有真实数据佐证

**6. 情境代入型（均分4.00）**
公式：`当[情境]时 + [意外发现/转折]` 或 `凌晨[时间] + [N个AI] + [动作]`
- 凌晨2:17，11个AI Agent在我的Mac上同时干活
- 当Agent替你值班：7x24小时的真相
- 规则：情境必须有画面感（时间/地点/数字）

### Tier 3: 避免（均分≤3.5）

**7. 陈述型（均分2.50）—— 禁用**
- ❌ 我跑了17个量化策略
- ❌ Mac本地跑AI的踩坑记录
- ❌ AI编程工具对比

## 平台适配规则

| 平台 | 标题长度 | 必含元素 | 禁忌 |
|------|---------|---------|------|
| 小红书 | ≤20字 | 1个数字+1个情绪词/类比 | 问号结尾、太学术 |
| 公众号 | 15-30字 | 判断句或类比 | 纯陈述、太长 |
| X/Thread | ≤70字符(首条) | 反直觉或数字冲击 | 模糊、无信息量 |
| 知乎 | 20-40字 | 学术感+实用价值 | 太口语、太标题党 |

## 自检清单

- [ ] 标题包含至少1个公式元素？
- [ ] 0.3秒内能产生画面感？
- [ ] 信息量足够（不说"一些""很多"）？
- [ ] 与同赛道其他标题有差异化？
- [ ] 目标平台的长度和风格适配？

## 标题生成流程

1. 写完正文后，基于核心观点生成5个候选（每类公式各1个）
2. 用自检清单过滤
3. 选择信息量最高+画面感最强的1个
4. 如果是系列文章，标题之间必须有"追问/悬念"串场
