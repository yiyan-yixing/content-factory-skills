## 设定师

### 1. 作者人设（替代网文的"世界观"）

```
人设定位：AI 写作实践者（不是理论家，是每天用 AI 写作的人）
信任锚点：
  - "我用 Claude 写了 200+ 篇公众号文章"
  - "日更 3000 字已经坚持 90 天"
  - "以下是实测数据，不是搬运"
调性：专业但不装，真实但有用，有观点不做和事佬
```

### 2. 读者旅程设计（替代网文的"角色关系"）

```
陌生读者 → 搜索进入文章
  → 信任（作者实测+数据对比）→ 关注公众号
  → 付费（加入知识星球"AI 写作实战圈"99 元/年）
  → 复购（推荐工具佣金 + 续费星球）

关键转化点：
  文末 CTA："想知道我用 AI 日更 3000 字的完整工作流？→ 星球见"
```

### 3. 平台风格指南

| 平台 | 风格 | 关键要求 |
|------|------|---------|
| 公众号 | 专业测评+数据驱动 | 对比表格+价格+评分 |
| 小红书 | 真实体验+种草感 | 个人感受+使用场景+emoji |
| 知乎 | 严谨分析+逻辑链 | 数据引用+优缺点+适用场景 |
| 抖音 | 痛点+解决方案 | 3 秒钩子+快速推荐+演示 |

**L1 交付物**：AuthorPersona + ReaderJourneyMap + PlatformStyleGuide[] → 传给 L2

## 审稿

### SEO 审查

```
✅ 标题含核心关键词 "AI 写作工具"
✅ 首段 100 字内回答搜索意图
✅ H2 含 4 个长尾词（推荐/哪个好/对比/免费）
✅ 关键词密度 3.2%（目标 2-5%）
⚠️ 内链不足 → 建议加 2-3 篇历史文章链接
```

### 种草审查

```
✅ 工具推荐基于真实使用场景
✅ 没有硬广感（"我实测了"而非"快去买"）
✅ 优缺点都写了（不是只说好话）
P1: Claude 推荐段落可以加一个"不适合"的场景，增强真实感
```

### 平台审查

```
✅ 公众号版：排版合理，段落<4行
✅ 小红书版：emoji 密度适当，标签 5 个
✅ 知乎版：逻辑链完整，有数据引用
✅ 抖音版：3 秒钩子到位
```
