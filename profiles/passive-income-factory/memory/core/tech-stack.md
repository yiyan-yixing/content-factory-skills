## 选型原则

- **SEO 优先**：选题必须经过搜索量验证，不写无人搜索的内容
- **一鱼多吃**：一次创作 → 5 平台分发 + 7 种形态复用
- **零边际**：数字产品和付费内容是被动收入核心（做一次，卖无限次）
- **私域底盘**：公众号+微信群是抗平台变化的底盘
- **工具链自动化**：5118 API + 壹伴 AI + 剪映 AI = 人工 15 分钟/篇
- **成本敏感**：优先用免费/低成本工具，付费工具按 API 量计费
