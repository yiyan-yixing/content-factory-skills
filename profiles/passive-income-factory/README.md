# 被动收入工厂 Profile

> 专为内容被动变现场景配置的内容工厂垂直包。
> 核心逻辑：一次创作 → 多平台分发 → 长尾搜索流量 → 持续收租

## 适用场景

- 公众号/头条/知乎 长青文矩阵（搜索型流量）
- 知乎盐选/番茄小说 付费连载
- 小红书种草 → 带货佣金
- 知识星球/小报童 付费专栏
- 数字产品（模板/电子书/Prompt 包）自动售卖
- 微信私域 0 佣金带货

## 与网文工厂的核心差异

| 维度 | 网文工厂 | 被动收入工厂 |
|------|---------|-------------|
| 内容形态 | 连续小说（50+ 章） | 长青文/短连载/种草文/数字产品 |
| 发布平台 | 起点/番茄/晋江 | 公众号+头条+知乎+小红书+抖音（5 平台） |
| 收入模式 | 付费追更+IP 授权 | 流量分成+付费专栏+带货+数字产品+IP |
| 内容长度 | 3000-5000 字/章 | 1500-3000 字/篇（长青文）或 300-800 字+图（小红书） |
| 更新频率 | 日更 3000 字 | 日更 1-2 篇，周末批量预生成 |
| 核心指标 | 完读率>40%、付费率>5% | 搜索排名、长尾阅读量、被动收入/篇 |
| 一鱼多吃 | 同平台连载 | 5 平台分发 + 7 种形态复用 |
| AI 自动化 | 生产层为主 | L0-L4 + 跨平台改写全链自动化 |

## 特化配置

### L0 主编 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 画像重点 | 搜索意图画像（用户搜什么 → 我写什么） |
| 情绪重点 | 信任感+获得感（不是情绪冲击，是"有用"） |
| 选题重点 | 长尾关键词分析 + 搜索量验证 + 竞争度评估 |
| 选题类型 | 工具测评/方法论/对比评测/清单合集/种草推荐 |

**选题必须过 SEO 验证**（网文工厂不需要，被动收入工厂必须）：
1. 用 5118/站长工具 挖掘长尾词
2. 用百度指数确认搜索趋势
3. 评估竞争度（专攻「高搜索+低竞争」）
4. 不写无人搜索的内容

### 设定师 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 世界观 | ❌ 不需要（非小说） |
| 人物 | → 作者人设（专业/可信/有温度） |
| 关系 | → 读者关系设计（关注→信任→付费→复购） |
| 风格 | → 平台适配风格（公众号专业/小红书轻松/知乎严谨） |

**产出变化**：
- 网文工厂：WorldBook + CharacterCard[] + RelationMap + StyleGuide
- 被动收入：AuthorPersona + ReaderJourneyMap + PlatformStyleGuide[]

### L2 编剧 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 故事弧线 | → 内容日历（发布节奏+分发时序） |
| 长线规划 | → 系列选题规划（10 篇一个主题簇） |
| 爆点设计 | → SEO 锚点设计（每篇植入 3-5 个长尾词） |
| 连载节奏 | → 分发节奏（首发→48h→72h 跨平台） |

**产出变化**：
- 网文工厂：StoryArc + LongTermPlan + HighlightList + RhythmChart
- 被动收入：ContentCalendar + TopicCluster[] + SEOAnchorMap + DistributionSchedule

### L3 写手 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 章节长度 | 1500-3000 字（长青文）或 300-800 字+6-9 图（小红书） |
| 开头钩子 | 标题含核心关键词 + 前 100 字回答搜索意图 |
| 更新节奏 | 日更 1-2 篇，周末批量预生成 3 天稿件 |
| 种草植入 | 产品使用场景自然嵌入（不是硬广） |

**多版本生成**：一次写 3000 字长文 → 自动拆解：
- 公众号版（原文 3000 字）
- 头条版（微调标题，1500-3000 字）
- 知乎版（改问答体，1500-3000 字）
- 小红书版（拆 6-9 图文卡，300-800 字+emoji+标签）
- 抖音版（提取 3 金句 → 30-90 秒脚本）

### 审稿 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 结构审查 | + SEO 合规检查（关键词密度 2-5%、H2 含关键词、首段回答意图） |
| 情绪强化 | → 信任感强化（数据引用、案例佐证、个人经验） |
| 节奏优化 | → 阅读体验优化（段落<4 行、关键信息加粗、小标题每 300 字） |
| 一致性检查 | + 种草植入检查（P0：硬广必须改写，P1：植入不够自然） |

**新增审稿维度**：
- SEO 审查：标题含核心词、首段回答搜索意图、正文关键词密度 2-5%
- 种草审查：产品植入是否自然、是否真实体验感、CTA 是否过度
- 平台审查：各平台格式合规（小红书 emoji、知乎逻辑结构、公众号排版）

### 运营 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 读者转化 | → 搜索流量转化（标题 SEO → 点击 → 阅读 → 关注/付费） |
| 社群设计 | → 私域沉淀（公众号→微信群→知识星球/小报童） |
| 留存设计 | → 系列内容留存（主题簇+连载钩子+更新通知） |
| 传播设计 | → 一鱼多吃传播（原文→图文→视频→金句多形态扩散） |

### 商务 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 付费墙 | → 免费内容引流 → 付费专栏/星球变现 |
| 会员 | → 知识星球 99 元/年 / 小报童 49-199 元 / 带货佣金 10-40% |
| 产品化 | → 数字产品打包（模板/电子书/Prompt 包，零边际成本） |
| IP 运营 | → 作者品牌 IP > 角色 IP（"那个 AI 写作的人" > 虚构角色） |

### 复盘官 — 特化

| 维度 | 被动收入特化 |
|------|-------------|
| 反馈收集 | + 搜索排名数据 + 各平台阅读/互动数据 + 带货转化数据 |
| 内容复盘 | → 哪些选题搜索流量高？哪些内容带货好？哪些平台收益高？ |
| 技能优化 | → SEO 关键词规则更新 + 种草植入技巧沉淀 + 平台算法变化应对 |
| 经验沉淀 | → 选题库+爆款模板+平台规则库（核心数字资产） |

## 推荐技术栈

| 层级 | 推荐选型 |
|------|---------|
| 发布平台 | 公众号（主阵地）+ 头条/知乎（公域引流）+ 小红书（种草引流）+ 抖音（短视频扩散） |
| SEO 工具 | 5118（关键词+改写 API）+ 站长工具（权重监控）+ 百度指数（趋势验证） |
| 公众号工具 | 壹伴（AI 排版+标题评分+图文分析） |
| 小红书工具 | 千瓜数据（热词+笔记创作）+ 创作者中心（笔记灵感） |
| 抖音工具 | 剪映（AI 文字成片+数字人+智能剪辑） |
| 跨平台 | KAWO（一键适配+排期发布）或 易撰（一键分发） |
| 知识付费 | 小报童/知识星球（起步）→ 面包多（数字产品 5% 抽成）→ 小鹅通/有赞（品牌化） |
| 带货 | 抖音精选联盟（15-40%）+ 小红书蒲公英（10-25%）+ 微信私域（0%） |
| AI 辅助 | Claude（内容工厂核心）+ Kimi/豆包/DeepSeek（补充改写） |
| 数据追踪 | 5118 排名监控 + 千瓜/飞瓜（社媒数据）+ 壹伴图文分析 |

## 收入管道优先级

```
启动期（1-3 月）：管道1 流量分成 → 管道4 数字产品
增长期（3-6 月）：管道2 付费专栏 → 管道6 带货佣金
规模期（6-12 月）：管道3 小说连载 → 管道7 IP 授权
持续期（12 月+）：全 7 管道并行，收入结构从"靠流量"→"靠信任"→"靠资产"
```

## 一鱼多吃标准流程

```
Step 1: @head-of-content SEO 驱动选题（5118 关键词验证）
Step 2: @writer 生成 3000 字长文（公众号版本）
Step 3: @reviewer SEO+种草双审查
Step 4: 5118 智能改写 API 自动生成多平台版本
  ├─→ 公众号：原文首发（壹伴 AI 排版+标题评分）
  ├─→ 头条：48h 后发（微调标题）
  ├─→ 知乎：72h 后发（改问答体）
  ├─→ 小红书：拆 6-9 图文卡+emoji+标签
  └─→ 抖音：3 金句→30-90秒脚本→剪映 AI 文字成片
Step 5: 数据追踪 → 复盘 → 优化下一轮
```
